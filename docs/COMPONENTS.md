# Component Directory

A guided map of the key components in `src/components/`. The goal is to help you find the right component quickly and understand what each one does.

---

## `src/components/ui/`

shadcn/ui primitives. These are auto-generated by the shadcn CLI and should not be edited by hand unless you are intentionally customising the design system.

| File | Primitive |
|---|---|
| `avatar.tsx` | Avatar with image and fallback initials |
| `badge.tsx` | Small status/category label chip |
| `button.tsx` | Button with size and variant props |
| `card.tsx` | Card container with header/content/footer slots |
| `carousel.tsx` | Embla-based carousel wrapper |
| `checkbox.tsx` | Accessible checkbox input |
| `dialog.tsx` | Modal dialog with overlay |
| `dropdown-menu.tsx` | Radix dropdown with items and separators |
| `input.tsx` | Text input with label support |
| `label.tsx` | Form label element |
| `scroll-area.tsx` | Custom scrollbar container |
| `select.tsx` | Native-style select with Radix under the hood |
| `separator.tsx` | Horizontal/vertical divider line |
| `sheet.tsx` | Side-panel drawer (used for mobile nav, forms) |
| `switch.tsx` | Toggle switch |
| `table.tsx` | Semantic table with styled cells and headers |
| `tabs.tsx` | Tab group with panel switching |
| `textarea.tsx` | Multi-line text input |
| `tooltip.tsx` | Hover tooltip |

## `src/components/layout/`

Site-wide layout components rendered on every public page.

| File | Description |
|---|---|
| `header.tsx` | Top navigation bar — logo, nav links loaded from the database, auth state, mobile sheet menu |
| `footer.tsx` | Site footer — links, social placeholders, contact email, copyright using `NEXT_PUBLIC_SITE_NAME` |
| `Logo.tsx` | Site logo — renders the logo image with alt text and tagline pulled from `NEXT_PUBLIC_SITE_NAME` |

## `src/components/home/`

Homepage section components. Each maps to a block type in the page builder. They receive pre-fetched data as props from the page server component.

| File | Block Type | Description |
|---|---|---|
| `hero-carousel.tsx` | `hero` (variant: carousel) | Animated carousel hero showing recent post cards with category colour coding |
| `hero-centered.tsx` | `hero` (variant: centered) | Centred full-width hero with title, subtitle, and CTA buttons |
| `hero-split.tsx` | `hero` (variant: split) | Two-column hero with text left, image right |
| `hero-bold.tsx` | `hero` (variant: bold) | Full-bleed bold hero with large background image and overlay text |
| `news-preview.tsx` | `news_preview` | Grid of latest posts with category badges; pulls live data |
| `events-preview.tsx` | `events_preview` | Upcoming events list with date, location, and price |
| `leadership-preview.tsx` | `leadership_preview` | Card grid of active leadership profiles |
| `gallery-teaser.tsx` | `gallery_teaser` | Horizontal photo strip from the most recent gallery album |
| `about-section.tsx` | `about_preview` | About preview with image, heading, body text, and a link |
| `cta-section.tsx` | `cta_section` | Generic call-to-action banner with heading, body, and a button |
| `features-grid.tsx` | `features_grid` | Features or services grid with icon, title, and description per item |
| `stats-bar.tsx` | `stats_bar` | Animated counter bar displaying key statistics |
| `image-banner.tsx` | `image_banner` | Full-width image banner with optional overlay text |

## `src/components/shared/`

Cross-cutting components used in multiple routes.

| File | Description |
|---|---|
| `block-renderer.tsx` | Central dispatcher — receives a list of `PageBlock` records and renders the correct component for each `blockType`. This is the integration point between the page builder data and the UI. |
| `post-card.tsx` | Post preview card used in the `news_preview` block, the `/news` listing, and the hero carousel. Displays title, excerpt, category badge, date, and cover image. |
| `page-header.tsx` | Inner page hero with title, subtitle, and optional breadcrumb — used on most listing pages |
| `inner-page-hero.tsx` | Variant inner-page hero with background image support |
| `article-hero.tsx` | Large hero used at the top of post and event detail pages |
| `theme-toggle.tsx` | Light/dark mode toggle button (next-themes) |

## `src/components/dashboard/`

Admin dashboard UI. All components in this folder are client components or are used exclusively within the `(dashboard)` route group.

### Core Layout

| File | Description |
|---|---|
| `sidebar.tsx` | Role-aware collapsible navigation sidebar. Nav items are shown or hidden based on the session user's role. |
| `topbar.tsx` | Dashboard topbar with breadcrumb, notification area, and user avatar/menu |

### Content Editors

| File | Description |
|---|---|
| `post-editor.tsx` | Full TipTap rich-text editor with toolbar (bold, italic, lists, links, image embed via media picker) |
| `event-form.tsx` | Create/edit form for events — title, slug, date, location, capacity, price, cover image |
| `course-form.tsx` | Create/edit form for learning courses — title, slug, description, cover image, published toggle |
| `lesson-form.tsx` | Create/edit form for lessons — title, slug, video URL, rich-text body, sort order |
| `publication-form.tsx` | Create/edit form for publications — title, slug, file upload, member-only toggle |
| `leadership-form.tsx` | Create/edit form for leadership profiles — name, title, bio, photo, sort order |
| `album-form.tsx` | Create/edit form for gallery albums — title, description, cover image |
| `newsletter-form.tsx` | Newsletter compose form — subject, HTML body (TipTap), recipient segment selection |
| `settings-form.tsx` | Site settings form — site name, contact email, social media URLs |

### Page Builder

| File | Description |
|---|---|
| `page-builder-client.tsx` | Visual page builder. Lists current page blocks, allows adding new blocks, reordering via drag-and-drop (`@dnd-kit`), and opening the per-block editor panel. Saves block order to the database. |
| `block-editor/block-editor-shell.tsx` | Shell that wraps per-block-type editors in a slide-over panel. Dispatches to the correct block editor component based on `blockType`. |
| `block-editor/hero-block-editor.tsx` | Block editor for `hero` — variant picker, title, subtitle, CTA link fields |
| `block-editor/rich-text-block-editor.tsx` | Block editor for `rich_text` — TipTap embed |
| `block-editor/gallery-teaser-block-editor.tsx` | Block editor for `gallery_teaser` — album selector |
| `block-editor/image-banner-block-editor.tsx` | Block editor for `image_banner` — image picker, overlay text |
| `block-editor/stats-bar-block-editor.tsx` | Block editor for `stats_bar` — add/edit/remove stat items |
| `block-editor/features-grid-block-editor.tsx` | Block editor for `features_grid` — add/edit/remove feature items with icon, title, body |
| `block-editor/objectives-block-editor.tsx` | Block editor for `objectives_list` — ordered list of objective strings |
| `block-editor/timeline-block-editor.tsx` | Block editor for `timeline` — add/edit/remove timeline events with year and description |
| `block-editor/about-preview-block-editor.tsx` | Block editor for `about_preview` — heading, body, image, link |
| `block-editor/simple-section-block-editor.tsx` | Generic block editor for blocks with only heading and body (e.g. `cta_section`) |

### Media and Gallery

| File | Description |
|---|---|
| `media-picker-modal.tsx` | Reusable dialog for selecting a file from the MinIO media library. Used by all form components that need image/file inputs. Accepts an `onSelect` callback. |
| `gallery-image-manager.tsx` | Full image management UI for a gallery album — drag-and-drop reorder, bulk upload, delete individual images |

### Members

| File | Description |
|---|---|
| `members-map.tsx` | Leaflet map (client-only, dynamic import) showing pins for members with a known location. Map center defaults to `[0, 0]` (world view). |
| `members-map-wrapper.tsx` | `next/dynamic` wrapper around `members-map.tsx` to prevent SSR errors |
| `members-page-client.tsx` | Combined member directory table + map tabs client component |
| `member-status-toggle.tsx` | Toggle button to activate/deactivate a member account |

### Navigation and Misc

| File | Description |
|---|---|
| `navigation-manager.tsx` | Drag-and-drop list for managing site navigation links — add, reorder, and delete links that appear in the site header |
| `data-table.tsx` | Generic sortable/filterable data table used across dashboard list pages |
| `contact-inbox.tsx` | Contact submission reader — marks submissions as read, shows full message |
| `announcement-actions.tsx` | Delete action for announcements |
| `new-announcement-sheet.tsx` | Sheet (drawer) form for quickly creating a new announcement |
| `export-csv-button.tsx` | CSV export button for registration and member list tables |

## `src/components/providers.tsx`

Top-level client providers wrapper mounted in `src/app/layout.tsx`. Wraps the app in `SessionProvider` (NextAuth), `ThemeProvider` (next-themes), and `QueryClientProvider` (TanStack Query), and mounts the `Toaster` (Sonner).
